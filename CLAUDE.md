# Правила работы в репозитории

Набор модов для FTB Infinity Evolved (Minecraft 1.7.10, Forge). Пользователь общается по-русски.

## Экономия лимитов (главное правило)

- **Не запускать тестовый клиент Minecraft** (`runClient`, Xvfb, xdotool, скриншоты игры). Это медленно и дорого.
  Проверку в игре делает пользователь; исправлять по его описанию, логу или скриншоту.
- **Не опрашивать фоновые процессы** в цикле (повторные `ReadNotifications`, `date`, `ls`, проверки лога).
  Запустил долгую задачу — дождаться одного уведомления.
- **Проверять дёшево:** `./gradlew build` для компиляции; тестовые папки и `-PinstanceDir=...` для задач установки.
- **Не читать файлы целиком без нужды:** искать `grep`, читать нужный фрагмент.
- **Без подагентов** и веб-поиска, если ответ известен или есть в репозитории.
- **Короткие ответы**, без пересказа уже сказанного.
- Если разговор стал длинным — предложить пользователю начать новый.

## Порядок работы

- Коммитить и пушить сразу в `main` (так попросил пользователь).
- При каждом изменении обновлять README: строку в нужной таблице и «Историю изменений»; поднимать версию мода
  (`build.gradle` и `VERSION` в главном классе мода).
- В README честно помечать, что проверено, а что нет.
- Ассеты Mojang (звуки, текстуры, шрифты) в репозиторий не класть — их собирает `gradlew install`
  из установленного у пользователя Minecraft.
- Личные данные пользователя (имя, пути с именем) в репозиторий не писать.

## Сборка и установка

- JDK 8 и 17; `./gradlew build` собирает все моды.
- `./gradlew install` (конфигурация IntelliJ «Install into modpack») ставит моды, паки и скрипты в сборку
  `<home>/curseforge/minecraft/Instances/FTB Infinity Evolved`; настройки — в `local.properties`.
